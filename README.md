# BuildQuantia

BuildQuantia is a free home-project planning toolkit that turns measurements into material quantities, estimates, and practical shopping lists.

## Current MVP
- Concrete slab calculator
- Flooring calculator
- Paint calculator
- Gravel calculator
- Mulch calculator
- Fence calculator
- Tile calculator
- Square footage calculator
- Project planner
- Save/copy results locally in the browser

## Free deployment
This repository is designed for GitHub Pages. After pushing, enable **Settings → Pages → Deploy from a branch → main → / (root)**, then the site will be available at:

https://taitnhaunt-oss.github.io/buildquantia/

The GitHub Actions workflow is also included for Pages-compatible deployments.
